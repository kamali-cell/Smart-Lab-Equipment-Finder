\# LabFind - Smart Laboratory Equipment Finder



\## Project Description



LabFind is a smart web-based system for finding and managing laboratory equipment.



Students can search equipment, view availability, reserve equipment, manage favorites, and view laboratory rooms.



Administrators can add, update, and delete laboratory equipment.

\## Continuous Integration



GitHub Actions is used for CI.



The CI pipeline:



1\. Checks out the source code.

2\. Sets up Python.

3\. Installs dependencies from `requirements.txt`.

4\. Checks Python files using `py\_compile`.

5\. Reports the CI result.
